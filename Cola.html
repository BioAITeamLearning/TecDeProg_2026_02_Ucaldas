Colas (Queue) en Python#

Una cola es una estructura de datos lineal que sigue el principio FIFO (First In, First Out): el primer elemento que entra es el primero en salir. Es como una fila del supermercado: el primero en llegar es el primero en ser atendido.

En este notebook implementamos una cola desde cero, usando una lista de Python como almacenamiento interno:

Operación

Qué hace

Complejidad

encolar (enqueue)

agrega un elemento al final

O(1)

desencolar (dequeue)

quita y devuelve el elemento del frente

O(n) con lista*

frente

consulta el primer elemento sin quitarlo

O(1)

final

consulta el último elemento sin quitarlo

O(1)

esta_vacia_cola

verifica si la cola no tiene elementos

O(1)

*Esta implementación es intencionalmente “a pedal” con list.pop(0) para mostrar cómo funciona una cola por dentro. El notebook avanzado usa collections.deque, que resuelve dequeue en O(1).

Operaciones principales#

crear_cola, encolar, desencolar, frente y final son el núcleo de la interfaz.

# =========================
#   COLA (QUEUE) — NÚCLEO
# =========================

def crear_cola():
    """Crea y retorna una cola vacía (lista)."""
    return []

def encolar(cola, elemento):
    """Enqueue: agrega un elemento al final de la cola."""
    cola.append(elemento)

def desencolar(cola):
    """
    Dequeue: elimina y retorna el elemento del frente de la cola.
    Retorna None si está vacía.
    Nota: pop(0) es O(n) pero es la versión a pedal con listas.
    """
    if esta_vacia_cola(cola):
        return None
    return cola.pop(0)

def frente(cola):
    """Peek front: retorna el elemento al frente sin eliminarlo. None si vacía."""
    if esta_vacia_cola(cola):
        return None
    return cola[0]

def final(cola):
    """Peek back: retorna el último elemento sin eliminarlo. None si vacía."""
    if esta_vacia_cola(cola):
        return None
    return cola[-1]

def esta_vacia_cola(cola):
    """True si la cola no tiene elementos."""
    return len(cola) == 0

Utilidades adicionales#

def tamanio_cola(cola):
    """Cantidad de elementos en la cola."""
    return len(cola)

def vaciar_cola(cola):
    """Elimina todos los elementos de la cola."""
    cola.clear()

Recorrer y buscar#

Igual que en la pila, estas funciones no modifican la cola: la recorren con ciclos, en orden FIFO (del frente hacia el final).

def recorrer_cola(cola):
    """
    Devuelve una lista con los elementos de la cola en orden FIFO,
    usando ciclo (sin slicing).
    """
    recorrido = []
    i = 0
    n = len(cola)
    while i < n:
        recorrido.append(cola[i])
        i += 1
    return recorrido

def buscar_en_cola(cola, objetivo):
    """
    Busca 'objetivo' en la cola usando ciclo.
    Retorna el índice relativo al frente (0 es frente) o -1 si no está.
    """
    i = 0
    n = len(cola)
    while i < n:
        if cola[i] == objetivo:
            return i
        i += 1
    return -1

Demostración#

if __name__ == "__main__":
    # Cola
    c = crear_cola()
    encolar(c, "A")
    encolar(c, "B")
    encolar(c, "C")
    print("Cola:", recorrer_cola(c))                       # ['A', 'B', 'C']
    print("Frente:", frente(c))                            # 'A'
    print("Desencolar:", desencolar(c))                    # 'A'
    print("Cola ahora:", recorrer_cola(c))                 # ['B', 'C']

Frente: A
Desencolar: A
Cola ahora: ['B', 'C']
