2. Listas#

2.1 Teoría#

  • Definición: list es una colección ordenada y mutable.

  • Características: ordenadas, permiten duplicados, heterogéneas (pueden contener distintos tipos).

  • Sintaxis: [] o list().

  • Usos típicos: coleccionar lecturas de sensores, listas de usuarios, colas pequeñas, etc.

2.2 Operaciones básicas#

# ======= OPERACIONES BÁSICAS DE LISTAS =======
# Crear listas
vacia = []
numeros = [1, 2, 3, 4]
mixta = ['Ana', 25, 3.14, True]

# Acceso por índice (0-based)
primero = numeros[0]  # 1
ultimo = numeros[-1]  # 4

# Modificar elementos
numeros[1] = 20  # ahora [1, 20, 3, 4]

# Agregar elementos
numeros.append(5)        # al final
numeros.insert(1, 10)    # en índice 1

# Eliminar elementos
valor = numeros.pop()    # elimina y devuelve último elemento
numeros.remove(10)       # elimina la primera ocurrencia del valor 10 (levanta ValueError si no existe)

# Mostrar resultados
print("Lista final:", numeros)
print("Elemento extraído con pop:", valor)

Lista final: [1, 20, 3, 4]
Elemento extraído con pop: 5

# ======= EJEMPLO PRÁCTICO: LECTURAS DE SENSOR =======
lecturas = [22.1, 22.5, 22.3, 22.8, 23.0, 22.7]

# Mínimo, máximo y media
min_val = min(lecturas)
max_val = max(lecturas)
media = sum(lecturas) / len(lecturas)

# Media móvil simple (ventana k)
def media_movil(data, k=3):
    if k <= 0:
        raise ValueError("k debe ser > 0")
    if len(data) < k:
        return []
    return [sum(data[i:i+k]) / k for i in range(len(data) - k + 1)]

mov3 = media_movil(lecturas, k=3)

print(f"Mín: {min_val}, Máx: {max_val}, Media: {media:.2f}")
print("Media móvil (k=3):", mov3)

Mín: 22.1, Máx: 23.0, Media: 22.57
Media móvil (k=3): [22.3, 22.53333333333333, 22.7, 22.833333333333332]

def estadisticas_calificaciones(calificaciones):
    if not calificaciones:
        return {"promedio": 0, "max": None, "min": None, "aprobados": 0}
    promedio = sum(calificaciones) / len(calificaciones)
    maxima = max(calificaciones)
    minima = min(calificaciones)

    return {"promedio": promedio, "max": maxima, "min": minima, "aprobados": aprobados}

#Ejercicio 3

def filtrar_outliers_iqr(data):
    # data: lista de números (no vacía preferentemente)
    if not data:
        return []
    s = sorted(data)
    n = len(s)
    # índices para percentiles 25 y 75 (usamos método simple)
    q1 = s[n // 4]
    q3 = s[(3 * n) // 4]
    iqr = q3 - q1
    lower = q1 - 1.5 * iqr
    upper = q3 + 1.5 * iqr
    return [x for x in data if lower <= x <= upper]

lecturas = [22.1, 22.5, 22.3, 50.0, 22.8, 23.0, 22.7]  # 50.0 es un outlier
print("Filtrado:", filtrar_outliers_iqr(lecturas))

Filtrado: [22.1, 22.5, 22.3, 22.8, 23.0, 22.7]

3. Tuplas#

3.1 Teoría#

  • Definición: colección ordenada e inmutable (tuple).

  • Características: ordenadas, inmutables, heterogéneas.

  • Sintaxis: (a, b, c) o tuple(iterable).

  • Usos comunes: retornar múltiples valores desde funciones, claves en diccionarios (si los valores son inmutables), representar registros constantes.

3.2 Operaciones con tuplas#

# ======= OPERACIONES CON TUPLAS =======
punto2D = (3.5, -1.2)
x = punto2D[0]
y = punto2D[1]

# Desempaquetado
x2, y2 = punto2D

# Tupla como retorno de función
def dividir(a, b):
    return a // b, a % b  # (cociente, resto)

c, r = dividir(17, 5)
print("Cociente:", c, "Resto:", r)

Cociente: 3 Resto: 2

4. Diccionarios#

4.1 Teoría#

  • Definición: colección de pares clave:valor (dict).

  • Claves: deben ser inmutables (str, int, tuple, …).

  • Características: acceso por clave, operaciones O(1) promedio, útiles para índices y búsquedas directas.

5. Funciones#

5.1 Teoría#

  • Definición: Bloques de código con nombre que realizan una tarea.

  • Sintaxis básica:

def nombre(param1, param2=valor_por_defecto):
    """Docstring: explicación corta."""

5.2 Ejemplos#

6. Funciones Lambda#

6.1 Teoría#

  • Las lambda son funciones anónimas de una sola expresión: lambda x, y: x + y

  • Útiles cuando se necesita una función pequeña y temporal (ej.: como argumento a map, filter, sorted).

  • No deben reemplazar funciones normales cuando la lógica es compleja; en esos casos, use def con docstring.

x = lambda a : a + 10
print(x(5))

15

x = lambda a, b : a * b
print(x(5, 6))

30

x = lambda a, b, c : a + b + c
print(x(5, 6, 2))

13

¿Por qué usar funciones lambda?#

El poder de lambda se muestra mejor cuando se utiliza como una función anónima dentro de otra función.

Digamos que tienes una definición de función que toma un argumento y ese argumento se multiplicará por un número desconocido:

def myfunc(n):
  return lambda a : a * n

mydoubler = myfunc(2)
mytripler = myfunc(3)

print(mydoubler(11))
print(mytripler(11))

22
33

7. Ejercicios integradores#

Ejercicio integrador (completo — usar listas, diccionarios, funciones y lambdas):

  1. Crea una lista de diccionarios estudiantes, donde cada elemento tiene: {‘nombre’: str, ‘edad’: int, ‘notas’: [float, …]}

  2. Implementa las funciones:

    • calcular_media_notas(estudiante) -> media de sus notas.

    • promedio_clase(estudiantes) -> promedio general (promedio de promedios).

    • top_n(estudiantes, n) -> devuelve los n estudiantes con mayor promedio (ordenados desc).

    • filtrar_por_edad(estudiantes, edad_min) -> devuelve estudiantes con edad >= edad_min.

  3. Usar lambda para ordenar estudiantes por nombre alfabéticamente y mostrar la lista ordenada.

from typing import List, Dict, Tuple

Estudiante = Dict[str, object]  # tipo informal para claridad

# Datos de ejemplo
estudiantes: List[Estudiante] = [
    {"nombre": "Ana", "edad": 20, "notas": [4.5, 3.8, 4.2]},
    {"nombre": "Luis", "edad": 22, "notas": [3.5, 2.8, 4.0]},
    {"nombre": "María", "edad": 19, "notas": [5.0, 4.9, 4.8]},
    {"nombre": "Pedro", "edad": 21, "notas": [2.9, 3.4, 3.0]},
]

def calcular_media_notas(est: Estudiante) -> float:
    notas = est.get("notas", [])
    return sum(notas) / len(notas) if notas else 0.0

def promedio_clase(estudiantes: List[Estudiante]) -> float:
    medias = [calcular_media_notas(e) for e in estudiantes]
    return sum(medias) / len(medias) if medias else 0.0

def top_n(estudiantes: List[Estudiante], n: int) -> List[Estudiante]:
    return sorted(estudiantes, key=lambda e: calcular_media_notas(e), reverse=True)[:n]

def filtrar_por_edad(estudiantes: List[Estudiante], edad_min: int) -> List[Estudiante]:
    return [e for e in estudiantes if e.get("edad", 0) >= edad_min]

# Ejecución
print("Media de Ana:", calcular_media_notas(estudiantes[0]))
print("Promedio de la clase:", promedio_clase(estudiantes))
print("Top 2 estudiantes:", [e["nombre"] for e in top_n(estudiantes, 2)])
print("Estudiantes con edad >= 21:", [e["nombre"] for e in filtrar_por_edad(estudiantes, 21)])

# Ordenar por nombre usando lambda
ordenado_por_nombre = sorted(estudiantes, key=lambda e: e["nombre"])
print("Ordenado por nombre:", [e["nombre"] for e in ordenado_por_nombre])

Promedio de la clase: 3.9
Top 2 estudiantes: ['María', 'Ana']
Estudiantes con edad >= 21: ['Luis', 'Pedro']
Ordenado por nombre: ['Ana', 'Luis', 'María', 'Pedro']

8. Buenas Prácticas y consejos#

  • Usa nombres descriptivos en snake_case.

  • Documenta funciones con docstring y, si quieres, con type hints.

  • Mantén funciones pequeñas y con una sola responsabilidad.

  • Evita repetir código (DRY).

  • Usa assert para pruebas rápidas y unittest/pytest para pruebas formales.

  • Sigue PEP 8: sangría 4 espacios, líneas < 79-99 caracteres, espacios alrededor de operadores.

  • Maneja errores con excepciones significativas (ValueError, TypeError, etc.).

def calcular_media_lista(nums: List[float]) -> float:
    """
    Calcula la media de una lista de números.

    Args:
        nums: lista de números (int o float).

    Returns:
        Media aritmética como float (0.0 si la lista está vacía).
    """
    return sum(nums) / len(nums) if nums else 0.0

  • Realizar transformaciones rápidas con lambdas y funciones como map/filter/sorted.

Sugerencias para continuar:

  • Practicar implementación de pilas y colas con listas.

  • Aprender árboles básicos (BST) y grafos si te interesa algoritmia.

  • Empezar a escribir tests con unittest o pytest.

  • Realizar pequeños proyectos: almacenamiento simple de pacientes, procesamiento de lecturas de sensores, análisis de archivos CSV con csv o pandas (este último cuando ya domines lo básico).
