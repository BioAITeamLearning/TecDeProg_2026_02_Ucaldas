Manejo de archivos en Python#

Hasta ahora, todo lo que has programado vive mientras el programa corre. Cierras el notebook y las listas, los diccionarios y los objetos desaparecen. Si quieres que algo sobreviva —una lista de estudiantes, el resultado de un cálculo, la configuración de un programa— tiene que salir de la memoria y quedar escrito en el disco. Eso es un archivo.

En este cuaderno vas a aprender a escribir y leer archivos en los tres formatos que más vas a encontrar: texto plano, CSV y JSON.

Note

Este cuaderno está pensado para que lo recorras solo, ejecutando cada celda en orden. Todas las celdas traen su salida ya guardada, así que puedes leerlo entero antes de correrlo. Los archivos que vamos a usar los crea el propio cuaderno: no necesitas descargar nada.

1. Memoria y disco: por qué existen los archivos#

Cuando escribes estudiantes = ["Ana", "Luis"], esa lista queda en la memoria RAM: un espacio de trabajo rapidísimo pero temporal. Al terminar el programa, se borra.

El disco es lo contrario: más lento, pero lo que escribes ahí queda. Un archivo es una secuencia de bytes guardada en disco, con un nombre.

Y aquí está la idea central de todo el cuaderno: el programa no puede tocar el disco directamente. Tiene que pedirle permiso al sistema operativo, y ese permiso se pide con una función que se llama open().

El ciclo es siempre el mismo, y tiene tres pasos:

abrir el archivo → leer o escribir → cerrar el archivo

Vamos a empezar por crear una carpeta donde guardar todo lo que hagamos, para no ensuciar el resto.

import os

# Creamos una carpeta de trabajo. exist_ok=True evita el error si ya existe.
os.makedirs("archivos_clase", exist_ok=True)

print("Carpeta lista.")
print("Estamos parados en:", os.getcwd())

Carpeta lista.
Estamos parados en: /private/tmp/arch/run

2. open(): abrir, usar, cerrar#

open() es la función que le pide al sistema operativo acceso a un archivo. Su forma más común es:

archivo = open(ruta, modo, encoding="utf-8")

Parámetro

Qué significa

ruta

el nombre del archivo, con su carpeta si hace falta

modo

qué vas a hacer con él: leer, escribir, agregar… (sección 4)

encoding

cómo se traducen las letras a bytes (sección 7)

open() no te da el contenido: te devuelve un objeto archivo, que es como un control remoto para ese archivo. Con ese objeto llamas a .write(), .read(), y al final .close().

# Abrimos en modo "w" (escritura). Si el archivo no existe, se crea.
archivo = open("archivos_clase/saludo.txt", "w", encoding="utf-8")

print("open() retornó:", archivo)
print("tipo:", type(archivo))

open() retornó: <_io.TextIOWrapper name='archivos_clase/saludo.txt' mode='w' encoding='utf-8'>
tipo: <class '_io.TextIOWrapper'>

Fíjate en lo que imprimió: no es el texto del archivo, es un objeto que representa la conexión abierta. Ahora sí podemos escribir en él y cerrarlo.

archivo.write("Hola desde Python\n")
archivo.close()        # <- cerrar NO es opcional

print("¿Sigue abierto?", not archivo.closed)

¿Sigue abierto? False

Por qué hay que cerrar#

Cuando escribes, Python no manda las letras al disco de inmediato: las va juntando en una memoria intermedia (un búfer) y las escribe de golpe cuando se llena o cuando cierras. Si el programa termina sin cerrar, lo que quedó en el búfer se pierde.

Además, cada archivo abierto consume un recurso del sistema operativo, y hay un límite.

Warning

Olvidar .close() es un error silencioso: el programa no falla, pero el archivo queda vacío o incompleto. Es dificilísimo de encontrar. Por eso casi nadie usa open() así — se usa with, que veremos ahora mismo.

3. with: la forma correcta de abrir#

with abre el archivo, ejecuta el bloque indentado y lo cierra solo al salir — incluso si algo sale mal en el medio. Es la forma que vas a usar siempre.

with open(ruta, modo, encoding="utf-8") as archivo:
    # aquí uso el archivo
# aquí ya está cerrado, automáticamente

La palabra as archivo le pone nombre al objeto que retornó open(). Compara las dos versiones:

# --- SIN with: hay que acordarse de cerrar ---
f = open("archivos_clase/version_a.txt", "w", encoding="utf-8")
f.write("escrito a mano\n")
f.close()

print("version_a cerrada:", f.closed)

version_a cerrada: True

# --- CON with: se cierra solo ---
with open("archivos_clase/version_b.txt", "w", encoding="utf-8") as f:
    f.write("escrito con with\n")
    print("¿Adentro del bloque está cerrado?", f.closed)

print("¿Afuera del bloque está cerrado?", f.closed)

¿Adentro del bloque está cerrado? False
¿Afuera del bloque está cerrado? True

Las dos escriben lo mismo, pero la segunda no se puede olvidar de cerrar. De aquí en adelante todos los ejemplos usan with.

El modo "w" borra el archivo entero apenas lo abres, antes incluso de que escribas nada. Es la forma más común de perder un archivo por accidente. Si lo que quieres es agregar, el modo es "a".

Vamos a verlo. Primero escribimos dos líneas con "w":

with open("archivos_clase/diario.txt", "w", encoding="utf-8") as f:
    f.write("lunes: primera clase\n")
    f.write("martes: taller\n")

with open("archivos_clase/diario.txt", "r", encoding="utf-8") as f:
    print(f.read())

lunes: primera clase
martes: taller

Ahora agregamos una línea con "a". Fíjate en que lo anterior sigue ahí:

with open("archivos_clase/diario.txt", "a", encoding="utf-8") as f:
    f.write("miercoles: parcial\n")

with open("archivos_clase/diario.txt", "r", encoding="utf-8") as f:
    print(f.read())

lunes: primera clase
martes: taller
miercoles: parcial

Y ahora abrimos otra vez con "w". Observa lo que pasa con las tres líneas anteriores:

with open("archivos_clase/diario.txt", "w", encoding="utf-8") as f:
    f.write("jueves: se borro todo lo anterior\n")

with open("archivos_clase/diario.txt", "r", encoding="utf-8") as f:
    print(f.read())

jueves: se borro todo lo anterior

Desaparecieron. Eso es exactamente lo que hace "w".

¿Y si el archivo no existe?#

Con "r", Python no se lo inventa: avisa que no lo encontró. Antes de leer, conviene preguntar si existe:

import os

ruta = "archivos_clase/no_existe.txt"

if os.path.exists(ruta):
    with open(ruta, "r", encoding="utf-8") as f:
        print(f.read())
else:
    print("Ese archivo no existe. Reviso el nombre o lo creo primero.")

Ese archivo no existe. Reviso el nombre o lo creo primero.

Note

Si intentas abrir en "r" un archivo que no existe, el programa se detiene con un mensaje que dice FileNotFoundError y el nombre del archivo. Cuando veas ese mensaje, el problema casi siempre es uno de dos: escribiste mal el nombre, o estás parado en otra carpeta (ver sección 8).

5. Escribir texto#

El método es .write(texto). Dos cosas que sorprenden al principio:

  1. write no agrega salto de línea. Si no pones \n, todo queda pegado en un solo renglón.

  2. write solo recibe texto. Si quieres guardar un número, tienes que convertirlo con str().

# Sin \n: todo queda en una sola linea
with open("archivos_clase/pegado.txt", "w", encoding="utf-8") as f:
    f.write("uno")
    f.write("dos")
    f.write("tres")

with open("archivos_clase/pegado.txt", "r", encoding="utf-8") as f:
    print(repr(f.read()))      # repr() nos deja ver si hay saltos de linea

'unodostres'

# Con \n: una linea por dato
with open("archivos_clase/separado.txt", "w", encoding="utf-8") as f:
    f.write("uno\n")
    f.write("dos\n")
    f.write("tres\n")

with open("archivos_clase/separado.txt", "r", encoding="utf-8") as f:
    print(repr(f.read()))

'uno\ndos\ntres\n'

Para guardar un número hay que convertirlo a texto:

edad = 20

with open("archivos_clase/edad.txt", "w", encoding="utf-8") as f:
    f.write(str(edad) + "\n")          # str() convierte el numero a texto
    f.write(f"El año entrante tendra {edad + 1}\n")   # o una f-string

with open("archivos_clase/edad.txt", "r", encoding="utf-8") as f:
    print(f.read())

20
El año entrante tendra 21

Escribir una lista completa#

Lo más común: recorrer una lista con un for y escribir una línea por elemento.

estudiantes = ["Ana", "Luis", "Sara", "Pedro"]

with open("archivos_clase/estudiantes.txt", "w", encoding="utf-8") as f:
    for nombre in estudiantes:
        f.write(nombre + "\n")

with open("archivos_clase/estudiantes.txt", "r", encoding="utf-8") as f:
    print(f.read())

Ana
Luis
Sara
Pedro

También existe .writelines(lista), pero tampoco agrega los saltos de línea, así que hay que ponerlos igual. Con un for queda más claro.

Hay cuatro maneras de leer, y sirven para cosas distintas.

Vamos a usar el archivo de estudiantes que acabamos de escribir.

# 1) read(): todo de una
with open("archivos_clase/estudiantes.txt", "r", encoding="utf-8") as f:
    contenido = f.read()

print(type(contenido))
print(repr(contenido))

<class 'str'>
'Ana\nLuis\nSara\nPedro\n'

# 2) readline(): una linea cada vez que se llama
with open("archivos_clase/estudiantes.txt", "r", encoding="utf-8") as f:
    print(repr(f.readline()))
    print(repr(f.readline()))

'Ana\n'
'Luis\n'

# 3) readlines(): una lista de lineas
with open("archivos_clase/estudiantes.txt", "r", encoding="utf-8") as f:
    lineas = f.readlines()

print(type(lineas))
print(lineas)

<class 'list'>
['Ana\n', 'Luis\n', 'Sara\n', 'Pedro\n']

# 4) for linea in archivo: la forma recomendada
with open("archivos_clase/estudiantes.txt", "r", encoding="utf-8") as f:
    for linea in f:
        print(repr(linea))

'Ana\n'
'Luis\n'
'Sara\n'
'Pedro\n'

El \n que sobra#

Fíjate en que todas las formas traen el \n pegado al final de cada línea. Casi nunca lo quieres: para quitarlo se usa .strip(), que elimina espacios y saltos de línea al principio y al final.

with open("archivos_clase/estudiantes.txt", "r", encoding="utf-8") as f:
    for linea in f:
        nombre = linea.strip()           # <- quita el \n
        print(f"[{nombre}] tiene {len(nombre)} letras")

[Ana] tiene 3 letras
[Luis] tiene 4 letras
[Sara] tiene 4 letras
[Pedro] tiene 5 letras

Un patrón que vas a repetir mucho#

Leer un archivo y dejarlo convertido en una lista limpia, lista para trabajar:

with open("archivos_clase/estudiantes.txt", "r", encoding="utf-8") as f:
    nombres = [linea.strip() for linea in f]     # for de una linea

print(nombres)
print("Son", len(nombres), "estudiantes")

['Ana', 'Luis', 'Sara', 'Pedro']
Son 4 estudiantes

Tip

¿Por qué el for es la forma recomendada? Porque lee el archivo de a una línea. Si el archivo tiene un millón de líneas, .read() las mete todas en memoria de un solo golpe; el for solo tiene una a la vez. Con archivos pequeños da igual, pero es buena costumbre.

7. La codificación: por qué siempre utf-8#

Un archivo de texto, por dentro, no guarda letras: guarda números. La codificación es la tabla que dice qué número corresponde a cada letra.

Para las letras del inglés casi todas las tablas coinciden. El problema son la ñ, las tildes y los símbolos como €: ahí cada tabla hace algo distinto, y si escribes con una y lees con otra, el texto sale corrupto.

utf-8 es la tabla estándar hoy: sirve para cualquier idioma. Por eso el parámetro encoding="utf-8" aparece en todos los ejemplos de este cuaderno.

texto = "Canción en español: el niño comió ñame"

with open("archivos_clase/acentos.txt", "w", encoding="utf-8") as f:
    f.write(texto + "\n")

with open("archivos_clase/acentos.txt", "r", encoding="utf-8") as f:
    print(f.read())

Canción en español: el niño comió ñame

Ahora el mismo archivo, leído con la tabla equivocada:

# latin-1 es otra tabla, antigua. Mismos bytes, interpretacion distinta.
with open("archivos_clase/acentos.txt", "r", encoding="latin-1") as f:
    print(f.read())

CanciÃ³n en espaÃ±ol: el niÃ±o comiÃ³ Ã±ame

Eso que ves —Ã³, Ã±— es el síntoma clásico de una codificación equivocada. Si algún día abres un archivo y las tildes salen así, ya sabes qué pasó.

Important

Pon siempre encoding="utf-8", tanto al escribir como al leer. Si lo omites, Python usa la codificación que el sistema operativo tenga por defecto, que cambia entre Windows, Mac y Linux. El mismo programa funcionaría en tu computador y fallaría en el de un compañero.

Armar rutas sin equivocarse#

Windows separa carpetas con \ y Mac/Linux con /. Para no tener que pensar en eso, se usa os.path.join(), que pone el separador correcto según el sistema.

import os

ruta = os.path.join("archivos_clase", "estudiantes.txt")
print("Ruta armada:", ruta)

print("¿Existe?        ", os.path.exists(ruta))
print("Tamaño en bytes:", os.path.getsize(ruta))
print("Solo el nombre: ", os.path.basename(ruta))
print("Solo la carpeta:", os.path.dirname(ruta))

¿Existe?         True
Tamaño en bytes: 20
Solo el nombre:  estudiantes.txt
Solo la carpeta: archivos_clase

9. CSV: datos separados por coma#

CSV significa Comma-Separated Values. Es la forma más simple de guardar una tabla: cada línea es una fila y las columnas van separadas por comas.

Lo importante: un CSV es un archivo de texto normal. Lo puedes abrir con open() y leerlo como cualquier otro. Vamos a escribir uno a mano para verlo por dentro:

with open("archivos_clase/notas.csv", "w", encoding="utf-8") as f:
    f.write("nombre,materia,nota\n")       # <- la primera linea son los titulos
    f.write("Ana,Tecnicas,4.5\n")
    f.write("Luis,Tecnicas,3.2\n")
    f.write("Sara,Tecnicas,4.8\n")

with open("archivos_clase/notas.csv", "r", encoding="utf-8") as f:
    print(f.read())

nombre,materia,nota
Ana,Tecnicas,4.5
Luis,Tecnicas,3.2
Sara,Tecnicas,4.8

Eso es todo lo que hay en un CSV. Cuando Excel abre este archivo, lo que hace es cortar cada línea por las comas y poner cada pedazo en una celda.

Podríamos leerlo así, a mano, con .split(","):

with open("archivos_clase/notas.csv", "r", encoding="utf-8") as f:
    for linea in f:
        partes = linea.strip().split(",")
        print(partes)

['nombre', 'materia', 'nota']
['Ana', 'Tecnicas', '4.5']
['Luis', 'Tecnicas', '3.2']
['Sara', 'Tecnicas', '4.8']

Funciona… hasta que un dato contiene una coma. Por ejemplo, el nombre "Pérez, Ana" partiría la línea en un pedazo de más y toda la tabla se desalinearía. Por eso Python trae un módulo que ya resuelve esos casos: csv.

Escribir con el módulo csv#

import csv

filas = [
    ["nombre", "materia", "nota"],
    ["Ana", "Tecnicas", 4.5],
    ["Luis", "Tecnicas", 3.2],
    ["Sara", "Tecnicas", 4.8],
]

# newline="" es obligatorio al escribir CSV: evita lineas en blanco de mas en Windows
with open("archivos_clase/notas2.csv", "w", encoding="utf-8", newline="") as f:
    escritor = csv.writer(f)
    escritor.writerows(filas)          # writerow() escribe una; writerows() varias

with open("archivos_clase/notas2.csv", "r", encoding="utf-8") as f:
    print(f.read())

nombre,materia,nota
Ana,Tecnicas,4.5
Luis,Tecnicas,3.2
Sara,Tecnicas,4.8

Leer con csv.reader#

csv.reader entrega cada fila como una lista.

import csv

with open("archivos_clase/notas2.csv", "r", encoding="utf-8", newline="") as f:
    lector = csv.reader(f)
    for fila in lector:
        print(fila)

['nombre', 'materia', 'nota']
['Ana', 'Tecnicas', '4.5']
['Luis', 'Tecnicas', '3.2']
['Sara', 'Tecnicas', '4.8']

Leer con csv.DictReader: más cómodo#

DictReader usa la primera línea como nombres de columna y entrega cada fila como un diccionario. Así no tienes que acordarte de que la nota es la posición 2.

import csv

with open("archivos_clase/notas2.csv", "r", encoding="utf-8", newline="") as f:
    lector = csv.DictReader(f)
    for fila in lector:
        print(fila)

{'nombre': 'Ana', 'materia': 'Tecnicas', 'nota': '4.5'}
{'nombre': 'Luis', 'materia': 'Tecnicas', 'nota': '3.2'}
{'nombre': 'Sara', 'materia': 'Tecnicas', 'nota': '4.8'}

import csv

# Ahora se accede por nombre de columna, que se lee mucho mejor
with open("archivos_clase/notas2.csv", "r", encoding="utf-8", newline="") as f:
    for fila in csv.DictReader(f):
        print(f"{fila['nombre']:6s} sacó {fila['nota']}")

Ana    sacó 4.5
Luis   sacó 3.2
Sara   sacó 4.8

La trampa del CSV: todo llega como texto#

Un archivo de texto no sabe de números. Todo lo que leas de un CSV llega como str, aunque se vea como un número. Si intentas sumar sin convertir, el resultado te va a sorprender:

import csv

with open("archivos_clase/notas2.csv", "r", encoding="utf-8", newline="") as f:
    primera = next(csv.DictReader(f))

print("La nota es:", repr(primera["nota"]))
print("Su tipo es:", type(primera["nota"]))
print('Sumar sin convertir:', primera["nota"] + primera["nota"])   # ¡concatena!

La nota es: '4.5'
Su tipo es: <class 'str'>
Sumar sin convertir: 4.54.5

Hay que convertir con float() o int() antes de calcular:

import csv

notas = []
with open("archivos_clase/notas2.csv", "r", encoding="utf-8", newline="") as f:
    for fila in csv.DictReader(f):
        notas.append(float(fila["nota"]))      # <- la conversion

print("Notas:", notas)
print("Promedio:", sum(notas) / len(notas))

10. JSON: datos con estructura#

El CSV sirve para tablas: filas y columnas, todo plano. Pero ¿cómo guardas un estudiante que tiene una lista de notas adentro? ¿O un diccionario dentro de otro? En CSV no cabe bien.

Para eso está JSON (JavaScript Object Notation). Es un formato de texto que guarda exactamente las mismas estructuras que ya conoces de Python:

Escribir JSON#

Se usa json.dump(objeto, archivo). Fíjate en los dos parámetros que lo hacen legible:

import json

estudiante = {
    "nombre": "Ana",
    "codigo": "2026001",
    "notas": [4.5, 3.8, 4.0],
    "activo": True,
    "observacion": None,
}

with open("archivos_clase/estudiante.json", "w", encoding="utf-8") as f:
    json.dump(estudiante, f, indent=2, ensure_ascii=False)

# Lo abrimos como texto plano para ver como quedo por dentro
with open("archivos_clase/estudiante.json", "r", encoding="utf-8") as f:
    print(f.read())

Leer JSON#

json.load(archivo) hace el camino inverso: lee el archivo y lo reconstruye como estructuras de Python. Ojo: no entrega texto, entrega el diccionario de verdad.

import json

with open("archivos_clase/estudiante.json", "r", encoding="utf-8") as f:
    datos = json.load(f)

print("Tipo:", type(datos))
print("Nombre:", datos["nombre"])
print("Notas: ", datos["notas"], "->", type(datos["notas"]))
print("Promedio:", sum(datos["notas"]) / len(datos["notas"]))

Tipo: <class 'dict'>
Nombre: Ana
Notas:  [4.5, 3.8, 4.0] -> <class 'list'>
Promedio: 4.1000000000000005

Note

Diferencia con el CSV: en JSON los números vuelven como números y las listas como listas. No hay que convertir nada. El formato guarda el tipo de cada dato, el CSV no.

Guardar una lista de diccionarios#

Es el caso más frecuente en la práctica: varios registros, cada uno con su estructura.

import json

curso = [
    {"nombre": "Ana",  "notas": [4.5, 3.8, 4.0]},
    {"nombre": "Luis", "notas": [3.0, 3.5]},
    {"nombre": "Sara", "notas": [4.8, 4.9, 5.0]},
]

with open("archivos_clase/curso.json", "w", encoding="utf-8") as f:
    json.dump(curso, f, indent=2, ensure_ascii=False)

with open("archivos_clase/curso.json", "r", encoding="utf-8") as f:
    recuperado = json.load(f)

for est in recuperado:
    promedio = sum(est["notas"]) / len(est["notas"])
    print(f"{est['nombre']:6s} {len(est['notas'])} notas  promedio {promedio:.2f}")

Luis   2 notas  promedio 3.25
Sara   3 notas  promedio 4.90

Para cerrar#

Lo esencial de este cuaderno cabe en seis líneas:

# Escribir
with open("archivo.txt", "w", encoding="utf-8") as f:
    f.write("una linea\n")

# Leer
with open("archivo.txt", "r", encoding="utf-8") as f:
    for linea in f:
        print(linea.strip())

Y las tres reglas que evitan casi todos los errores:

  1. Siempre with. Nunca te vas a olvidar de cerrar.

  2. Siempre encoding="utf-8". Las tildes van a funcionar en cualquier computador.

  3. "w" borra, "a" agrega. Cuando dudes, piensa qué pasa si el archivo ya existía.
