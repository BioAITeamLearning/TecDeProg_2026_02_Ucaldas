Pilas (Stack) en Python#

Una pila es una estructura de datos lineal que sigue el principio LIFO (Last In, First Out): el último elemento que entra es el primero en salir. Es exactamente como una pila de platos: solo puedes tomar (o dejar) un plato desde arriba.

En este notebook implementamos una pila desde cero, usando una lista de Python como almacenamiento interno, con las operaciones clásicas:

Operación

Qué hace

Complejidad

apilar (push)

agrega un elemento en la cima

O(1)

desapilar (pop)

quita y devuelve el elemento de la cima

O(1)

cima (peek)

consulta el elemento de la cima sin quitarlo

O(1)

verifica si la pila no tiene elementos

O(1)

tamanio_pila

cuenta los elementos

O(1)

Operaciones principales#

crear_pila, apilar, desapilar y cima son el núcleo de la interfaz: todo lo demás se construye sobre estas cuatro funciones.

# =========================
#   PILA (STACK) — NÚCLEO
# =========================

def crear_pila():
    """Crea y retorna una pila vacía (lista)."""
    return []

def apilar(pila, elemento):
    """Push: agrega un elemento en la cima de la pila."""
    pila.append(elemento)

def desapilar(pila):
    """Pop: elimina y retorna el elemento en la cima. Retorna None si está vacía."""
    if esta_vacia_pila(pila):
        return None
    return pila.pop()

def cima(pila):
    """Peek: retorna el elemento en la cima sin eliminarlo. Retorna None si está vacía."""
    if esta_vacia_pila(pila):
        return None
    return pila[-1]

def esta_vacia_pila(pila):
    """True si la pila no tiene elementos."""
    return len(pila) == 0

def tamanio_pila(pila):
    """Cantidad de elementos en la pila."""
    return len(pila)

Utilidades adicionales#

Operaciones de mantenimiento que no forman parte de la interfaz mínima de una pila, pero que son prácticas en el día a día.

def vaciar_pila(pila):
    """Elimina todos los elementos de la pila."""
    # A pedal: usar clear() es válido; también podrías hacer pops en ciclo
    pila.clear()

Recorrer y buscar#

Estas funciones no modifican la pila: solo la consultan usando ciclos, sin recurrir a slicing ([::-1]) para reforzar el manejo explícito de índices.

def recorrer_pila(pila, desde_cima=True):
    """
    Devuelve una lista con los elementos recorridos usando ciclos.
    - desde_cima=True: desde la cima hacia el fondo (LIFO visual).
    - desde_cima=False: desde el fondo hacia la cima (orden de inserción).
    """
    recorrido = []
    n = len(pila)
    if desde_cima:
        i = n - 1
        while i >= 0:
            recorrido.append(pila[i])
            i -= 1
    else:
        i = 0
        while i < n:
            recorrido.append(pila[i])
            i += 1
    return recorrido

def buscar_en_pila(pila, objetivo):
    """
    Busca 'objetivo' en la pila usando ciclo.
    Retorna el índice relativo a la base (0 es fondo) o -1 si no está.
    """
    i = 0
    n = len(pila)
    while i < n:
        if pila[i] == objetivo:
            return i
        i += 1
    return -1

Copiar e invertir#

clonar_pila crea una copia independiente. invertir_pila cambia el orden in-place, usando solo pop/append (sin reversed() ni slicing) para mostrar cómo se logra el mismo resultado apoyándose en el propio principio LIFO.

def clonar_pila(pila):
    """Crea una copia de la pila usando ciclos (sin slicing)."""
    copia = []
    i = 0
    n = len(pila)
    while i < n:
        copia.append(pila[i])
        i += 1
    return copia

def invertir_pila(pila):
    """Invierte la pila in-place usando solo pops y appends (a pedal)."""
    aux = []
    # pasar todo a aux (quedará en orden invertido)
    while not esta_vacia_pila(pila):
        aux.append(pila.pop())
    # regresar a pila
    while len(aux) > 0:
        pila.append(aux.pop())

Demostración#

if __name__ == "__main__":
    # Pila
    p = crear_pila()
    apilar(p, 10)
    apilar(p, 20)
    apilar(p, 30)
    print("Pila (desde cima):", recorrer_pila(p, True))   # [30, 20, 10]
    print("Cima:", cima(p))                                # 30
    print("Desapilar:", desapilar(p))                      # 30
    print("Pila ahora:", recorrer_pila(p, True))           # [20, 10]
    invertir_pila(p)
    print("Pila invertida:", recorrer_pila(p, True))       # [10, 20]
