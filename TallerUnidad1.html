B3 · Pila y cola a la vez#

Tienes una pila P y una cola C, las dos vacías. Aplica en orden:

  1. En las dos, mete 1, luego 2, luego 3.

  2. Saca uno de P y mételo en C.

  3. Saca uno de C y mételo en P.

  4. Saca uno de P.

Responde: ¿qué quedó en P y qué quedó en C? ¿Qué valor se sacó en el paso 4?

  7. desencolar()

  • b) Dibuja el arreglo físico después del paso 9, con sus índices.

B7 · ¿Qué imprime? (ojo con el valor por defecto)

class Carrito:
    def __init__(self, items=[]):
        self.items = items
    def agregar(self, x):
        self.items.append(x)

a = Carrito()
b = Carrito()
a.agregar("pan")
print(a.items, b.items)

B8 · ¿Qué imprime? (herencia y super())

class Empleado:
    def __init__(self, nombre):
        self.nombre = nombre
    def saludo(self):
        return f"Soy {self.nombre}"

class Jefe(Empleado):
    def __init__(self, nombre, area):
        super().__init__(nombre)
        self.area = area
    def saludo(self):
        return super().saludo() + f", jefe de {self.area}"

print(Empleado("Ana").saludo())
print(Jefe("Luis", "Sistemas").saludo())
print(isinstance(Jefe("Luis", "Sistemas"), Empleado))

B9 · ¿Qué imprime? (protocolos)

class Caja:
    def __init__(self, cosas):
        self.__cosas = list(cosas)
    def __len__(self):
        return len(self.__cosas)
    def __contains__(self, x):
        return x in self.__cosas
    def __iter__(self):
        return iter(tuple(self.__cosas))

c = Caja(["tuerca", "tornillo", "clavo"])
print(len(c))
print("clavo" in c)
print([x.upper() for x in c])
print(bool(Caja([])))

Parte C — Casos de la vida cotidiana#

Cada caso dice exactamente qué hacer. Tradúcelo a código usando Pila, Cola o ColaCircular, y al final de cada uno imprime el estado.

C1 · El historial del navegador (pila)#

Estás navegando. Cada página visitada entra al historial; el botón atrás saca la última.

  1. Visita uni.edu

  2. Visita uni.edu/notas

  3. Visita uni.edu/notas/2026

  4. Imprime en qué página estás (sin sacarla)

  5. Presiona atrás dos veces y muestra a dónde llegaste cada vez

  6. Visita uni.edu/horario

  7. Imprime cuántas páginas quedan en el historial y el historial completo

C2 · La fila de la cafetería (cola)#

  1. Llegan, en este orden: Ana, Luis, Sara, Pedro

  2. Imprime a quién le toca y quién es el último de la fila

  3. Atiende a dos personas y muestra el nombre de cada una

  4. Llega Camila

  5. Sara se cansa y se va: retírala sin atenderla (pista: saca y vuelve a encolar a los demás)

  6. Imprime la fila final y cuántos faltan

C3 · Las notificaciones del celular (cola circular)#

Tu celular solo muestra las últimas 3 notificaciones. Cuando llega una nueva y no hay espacio, la más vieja desaparece.

  1. Crea la cola circular con capacidad 3

  2. Llegan en este orden: "WhatsApp", "Correo", "Calendario"

  3. Imprime las notificaciones visibles

  4. Llega "Banco" — muestra cuál desapareció

  5. Llega "Instagram" — muestra cuál desapareció

  6. Imprime las visibles al final

C4 · Deshacer y rehacer en un editor (dos pilas)#

  1. Escribe "Hola", luego " mundo", luego "!"

  2. Imprime el texto completo

  3. Deshaz dos veces e imprime el texto después de cada una

  4. Rehaz una vez e imprime el texto

  5. Escribe " clase" — y borra lo que quedaba por rehacer

  6. Intenta rehacer: debe avisar que no hay nada

  7. Imprime el texto final

C5 · Turnos del laboratorio (cola circular, rotando)#

Tres equipos —E1, E2, E3— se turnan el microscopio. Cada equipo necesita turnos distintos: E1 necesita 3, E2 necesita 1, E3 necesita 2.

  1. Encola los tres equipos

  2. Mientras quede alguno con turnos pendientes:

    • saca el del frente

    • imprime "usa el microscopio: <equipo>"

    • réstale un turno

    • si todavía le quedan, vuélvelo a encolar al final

  3. Imprime el orden completo en que se usaron los turnos

  4. ¿Cuántas veces se usó el microscopio en total?

Parte D — Programación#

Ahora sin pasos dados: lee el requerimiento y decide tú cómo resolverlo.

D1 · La clase Producto#

Crea una clase Producto con nombre, precio y cantidad.

  • El precio se guarda en __precio y se expone con @property. No puede ser negativo.

  • valor_total() retorna precio * cantidad.

  • __repr__ muestra algo legible.

  • __eq__: dos productos son el mismo si tienen el mismo nombre.

Crea tres productos, intenta poner un precio negativo y muestra que falla.

D2 · La clase Pedido#

Crea una clase Pedido que guarde varios Producto.

  • agregar(producto) y retirar(nombre).

  • total() suma el valor de todos.

  • Soporta len(pedido), for p in pedido, "arroz" in pedido y print(pedido).

  • La lista interna no puede alcanzarse desde fuera.

D3 · Herencia#

Crea PedidoConDescuento(Pedido) que reciba un porcentaje de descuento y sobrescriba total() aplicándolo. Reutiliza el total del padre con super().

Comprueba que len(), in y el recorrido siguen funcionando sin que los hayas vuelto a escribir.

D4 · Polimorfismo#

Escribe una función imprimir_factura(pedidos) que reciba una lista con pedidos de los dos tipos e imprima el total de cada uno, sin preguntar de qué tipo es.

D5 · Paréntesis balanceados (pila)#

Escribe esta_balanceado(texto) que verifique que cada (, [ y { se cierra con su pareja y en el orden correcto.

Pruébalo con: "({[]})" → True, "(]" → False, "(((" → False, "" → True.

D6 · Invertir una cola (pila + cola)#
